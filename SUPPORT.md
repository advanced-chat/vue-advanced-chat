# Support

Advanced Chat Components is maintained by an open-source community. Support is provided on a
best-effort basis without guaranteed response or resolution times.

## Usage And Integration Questions

Use [GitHub Discussions Q&A](https://github.com/advanced-chat/advanced-chat-components/discussions/categories/q-a)
for setup help, API usage, theming questions, framework integration, and troubleshooting that has
not been confirmed as a library defect.

Include the package name and version, framework and browser versions, a minimal reproduction, the
relevant code, and the complete error message. Remove secrets and private data.

## Bugs

Use the repository's bug report issue form for reproducible behavior caused by the library:

<https://github.com/advanced-chat/advanced-chat-components/issues/new/choose>

Search existing issues first. A minimal public reproduction makes a report actionable. General
implementation questions and project-specific backend behavior belong in Discussions rather than
the issue tracker.

## Security

Do not report vulnerabilities in issues or Discussions. Follow [`SECURITY.md`](SECURITY.md) and use
the private advisory route:

<https://github.com/advanced-chat/advanced-chat-components/security/advisories/new>

## Scope Of Support

The project can help with its documented public API and reproducible behavior in supported release
lines. It cannot provide private application debugging, architecture consulting, implementation
services, or support for third-party backends and frameworks beyond demonstrating whether the
library contract is working as documented.
